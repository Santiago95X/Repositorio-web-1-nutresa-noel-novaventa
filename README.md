# Sazón - Módulo de Nutrición

Este es el desarrollo del módulo de nutrición para el proyecto Sazón, basado en el ecosistema de Grupo Nutresa. 

## ¿Qué incluye mi parte?
- **Catálogo Nutricional:** Tarjetas responsivas con información de recetas, macros y calorías.
- **Buscador y Filtros:** Filtrado por texto y por metas personales (bajar, subir de peso).
- **Conexión con API:** El frontend consume los datos a través de un servicio asíncrono (`fetch`) configurado en `api.config.js`.
- **Vista de Detalle:** Página independiente para ver la receta a fondo con barras de progreso de calorías.

## ¿Cómo correrlo?
1. Clonar el repositorio.
2. Abrir el `index.html` con Live Server (o cualquier servidor local).
3. Si estás probando la API, asegúrate de levantar el backend en el puerto `8080`.
